# TT Firs Neue Font Files

To use the TT Firs Neue font in the app, please add the following font files to this directory:

- `TTFirsNeue-Regular.ttf`
- `TTFirsNeue-Medium.ttf`
- `TTFirsNeue-Bold.ttf`

## How to add fonts:

1. Download or obtain the TT Firs Neue font files (you may need to purchase or obtain a license)
2. Place the `.ttf` files in this `assets/fonts/` directory
3. Make sure the file names match exactly as listed above
4. Restart your Expo development server

The app will automatically load these fonts and apply them to task titles.
